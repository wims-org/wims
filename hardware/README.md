# WIMS Hardware

## Wireless

This scanner is based on a ESP32 and can be used wirelessly via WiFi and a battery pack. Great if you combine it e.g.
with your smartphone or if you just want to check to location of a thing, which you see on the scanners display.

## Wired

This scanner is wired via USB and can be used together with the WIMS cli as a stationary scanner.
